# 게시글 작성 가이드 (어드민 사용법 + SEO · GEO · AEO)

## 1. 어드민 여는 법

1. 사이트 폴더(`ulsan-jeong-clinic`)에서 `node tools/admin-server.js` 실행 (또는 Claude에게 "어드민 켜줘")
2. 크롬에서 `http://localhost:8080/admin/` 접속
3. 비밀번호 입력 — `tools/admin-config.json`의 `password` 값 (처음 값: `bareul3375`, 파일에서 바꿀 수 있음)

어드민에서 저장하면 자동으로 다음이 처리됩니다.
- `pages/columns/_data/<슬러그>.json` 에 입력값 저장 (원본)
- `pages/columns/<슬러그>.html` 생성 (홈페이지에 보이는 글)
- 칼럼 목록 페이지 갱신, 이전/다음 글 링크 갱신
- 모든 페이지 SEO 데이터(구조화 데이터·OG 태그)와 `sitemap.xml` 갱신

**주의:** 이 어드민은 내 컴퓨터에서 돌아가는 로컬 프로그램입니다. 글을 쓴 뒤 홈페이지가 호스팅(서버)에 올라가 있다면, 바뀐 파일(`pages/columns/`, `assets/img/columns/`, `sitemap.xml`)을 다시 업로드해야 인터넷에 반영됩니다.

## 2. 입력 항목 설명

| 항목 | 규칙 | 이유 |
|---|---|---|
| 제목 | 핵심 키워드를 앞에, 질문형 또는 "키워드 + 무엇/왜/어떻게". 60자 이내 | 검색 결과 제목, AI 답변의 출처 제목 |
| 작성자 | 기본값 바를정한의원 의료진 | 글쓴이 신호(E-E-A-T) |
| 카테고리 | 통증·추나 / 안면비대칭·턱관절 / 소화기 / 다이어트 / 한의원 소식 | 분류, 구조화 데이터의 articleSection |
| description | 첫 문장에 결론, 120~150자 | 검색 결과 요약문 |
| keywords | 지역+증상+치료 조합 3~5개, 쉼표 구분 | 보조 신호 |
| schema | 비워도 됨. 추가 JSON-LD가 있을 때만 붙여넣기 | 기본 구조화 데이터(글·FAQ·병원·경로·의료진)는 자동 생성 |
| 내용 | 소제목(H2)은 환자가 검색창에 칠 문장. 소제목 바로 아래 "정답 박스"로 한 문장 결론 | H2는 자동 목차가 되고, 정답 박스는 AI 답변 발췌 단위 |
| 썸네일 | 가로형(16:9) 권장. 사이트 사진 중에서 고를 수도 있음 | 목록 카드, 글 상단, 공유 미리보기 |
| 썸네일 alt값 | 사진 내용을 문장으로 | 이미지 검색, 접근성 |
| 핵심 요약 | 한 줄에 하나, 3~4개. 숫자·기간·횟수 등 구체적 사실 | AI 검색이 그대로 인용하는 부분 |
| 자주 묻는 질문 | 3~5개. 질문은 실제 검색 문장, 답은 결론부터 2~3문장 | FAQ 구조화 데이터 자동 생성 |
| 참고 자료 | 한 줄에 하나. 기관·학회·논문·원내 페이지 | 근거 있는 글만 AI가 인용 |
| 글 주소(슬러그) | 영문 소문자·숫자·하이픈. 비우면 자동 생성 | 공개 후 바꾸면 주소가 바뀜 |

## 3. 에디터 사용 팁

- **붙여넣기**: 블로그 원고를 그대로 붙여넣으면 서식이 정리되어 들어갑니다. 붙여넣은 뒤 소제목을 "소제목 H2"로 바꿔 주세요.
- **정답 박스**: 커서를 문단에 두고 "▣ 정답 박스"를 누르면 그 문단이 초록 테두리 박스가 됩니다. 다시 누르면 해제.
- **체크리스트**: 증상 목록, 생활 수칙에 사용.
- **이미지**: 🖼 버튼으로 넣으면 `assets/img/columns/`에 저장되고 alt 입력창이 뜹니다.
- **미리보기**: "저장하고 공개" 후 미리보기 버튼으로 실제 페이지를 확인합니다. 임시저장 글은 홈페이지에 보이지 않습니다.

## 4. 하지 말아야 할 것

- 치료 전후 환자 사진, 환자 얼굴 사진 (의료광고 심의 문제 — 필요하면 심의 후 게시)
- "완치", "100% 효과", "최고" 같은 단정 표현 → "개인차가 있지만 보통 …"으로
- 다른 한의원 이름·브랜드가 들어간 이미지
- 같은 키워드를 억지로 반복하기
- 블로그 글을 토씨 하나 안 바꾸고 올리기 (중복 콘텐츠). 홈페이지용으로 문장을 다듬기

## 5. 추천 주제 (원고 자료에 이미 있는 것)

- 턱에서 소리가 난다면: 턱관절 장애 자가진단과 개구 테스트
- 안면비대칭·턱관절 치료, 추나와 침은 무엇이 다를까
- 안면비대칭 치료 기간은 얼마나 걸릴까 (원인 유형별)
- 턱관절 안면비대칭, 방치하면 왜 더 오래 걸릴까
- 목디스크 증상 6가지와 원인 4가지
- 밤에 심해지는 어깨 통증, 오십견의 3단계
- 운동 후 어깨 근육 긴장, 예방 스트레칭
- 소화제를 먹어도 그때뿐이라면: 담적병 이야기
- 한방다이어트 4계절 체질, 나는 어떤 체질일까

## 6. 어드민 없이 손으로 쓸 때

`_template.html`을 복사해 대괄호를 채우고, 사이트 폴더에서 `node tools/seo-inject.js`를 실행하면 됩니다. 단, 이렇게 만든 글은 어드민 목록에 자동으로 나타나지 않으므로 어드민의 "전체 다시 생성" 버튼을 한 번 눌러 가져오기를 하세요.
